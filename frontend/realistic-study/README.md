# Estudo realista da penseira

Cena estática da penseira, dos livros e do gabinete. Fica fora do app Next, para a limpeza do frontend seguir sem esta cena no meio.

Na pasta `frontend`:

```
npx --yes serve -l 4173 .
```

Abra http://127.0.0.1:4173/realistic-study/

O three usado é o que já está em `node_modules`. Não abra o `index.html` direto pelo disco.
